This project is supposed to help you pass your driving school exam.
So far, the only micro improvement I have over the main site is the fact that when you are choosing subtopics in the test practice part of the application, the subtopics that do not have any questions
will not be selectable so that you don't have to click around randomly when you're not sure what you're supposed to practice, which was something I found very annoying when I was preparing for the exam.

Upcoming:

JWT-based authentication.
Admin Page that allows you to add/edit questions.
Profile page with a progress bar that shows you how many questions you have answered so far while also tracking which ones you got wrong or right, whilst also highlighting the subtopics in which you got questions wrong so that you know which ones you need to work on.
Styling.
Adding the rest of the questions.
Test implementation. (Maybe I'll add a quasi-test just for show.)


I have noticed many people fail their tests, and although I know that is mostly because they did not prepare for it since it isn't very difficult, I am hoping to increase the percentage of people that pass the test.
